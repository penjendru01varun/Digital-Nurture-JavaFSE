===========================================
HANDS-ON 1: Environment Setup & Project Structure
===========================================

File: angular.json
Purpose: Configuration file for Angular CLI. Defines project settings, build configurations, development server options, asset paths, styles, scripts, and budget thresholds for production builds.

File: tsconfig.json
Purpose: Base TypeScript configuration for the entire workspace. Controls TypeScript compiler options like target version, module system, strict type checking, and path mappings used across all projects in the workspace.

File: tsconfig.app.json
Purpose: TypeScript configuration specific to the application. Extends tsconfig.json and includes settings for building the app, such as output directory, file inclusions, and compiler options optimized for the application code.

File: package.json
Purpose: NPM package manifest file. Lists all project dependencies (Angular core, CLI, libraries), devDependencies, scripts for building/serving/testing, and metadata about the project (name, version, description).

File: src/main.ts
Purpose: Application entry point. Bootstraps the Angular application by either loading the AppModule (NgModule approach) or bootstrapping the root AppComponent directly (standalone approach). This is the first code executed when the app loads.

File: src/app/app.module.ts (or app.config.ts in standalone mode)
Purpose: (NgModule approach) Defines the root NgModule that declares all components, imports required modules, and provides services. (Standalone approach) app.config.ts provides application-wide configuration including providers, interceptors, and store configurations.

File: src/app/app.component.ts
Purpose: Root component of the application. Contains the @Component decorator with selector 'app-root', defines the template, styles, and component logic. Acts as the main container for the entire Angular app.

File: src/index.html
Purpose: Main HTML page loaded by the browser. Contains the <app-root> tag where Angular bootstraps the application. Includes meta tags, title, and links to external resources. This is the single HTML file served by the server.

Budget Configuration in angular.json:
- maximumWarning: 2MB - Triggers a warning if bundle size exceeds this threshold
- maximumError: 5MB - Triggers an error and fails the build if bundle size exceeds this threshold
- These help monitor and control application bundle sizes to ensure optimal loading performance
